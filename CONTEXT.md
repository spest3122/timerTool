# TimerTool

A multi-lingual study companion for practicing time expressions, vocabulary, and pronunciation.

## Language

**Timer**:
A practice module for reading and saying clock times across supported languages.
_Avoid_: Clock, stopwatch

**Quiz**:
An interactive question-and-answer trainer for testing comprehension and language recall.
_Avoid_: Test, exam

**Speaker**:
A speech synthesis practice tool that reads numbers, times, and vocabulary aloud using system voices.
_Avoid_: Audio player, TTS player

**Vocab**:
A flashcard and vocabulary overview tool for browsing and learning words and phrases.
_Avoid_: Wordlist, dictionary

**Recorder**:
An audio recording and playback tool for capturing and self-evaluating spoken language practice.
_Avoid_: Voice memo, dictaphone

## Retired Terms

**Convo**:
An experimental turn-based interactive dialogue simulation. Retired from the core learning domain.
_Avoid_: Conversation, dialogue trainer
